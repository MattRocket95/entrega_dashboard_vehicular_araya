# SQL y base de datos

La actividad utiliza las tablas entregadas previamente por el profesor:

- `conductores`
- `vehiculos`
- `autorizaciones`
- `reportes_estado`

La aplicación no requiere crear tablas adicionales para funcionar.

El bucket utilizado para evidencias es:

`evidencias-vehiculares`

La actividad establece un tamaño máximo de 800 KB por imagen.

Si se requiere reconstruir la infraestructura en otro proyecto Supabase, se debe utilizar el DDL entregado por el profesor y configurar el bucket y sus políticas de Storage en el proyecto destino.

No se incluyen credenciales ni claves de Supabase en este repositorio.
